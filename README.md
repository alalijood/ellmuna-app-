# Ellmuna App

An all-in-one academic assistance mobile application tailored for high school and university students in Saudi Arabia[span_0](start_span)[span_0](end_span). Designed to simplify academic progress tracking, calculation, and university exploration through a clean interface[span_1](start_span)[span_1](end_span).

## Key Features

* **High School Weighted Average Calculator:** Accurate calculation of admission scores based on High School, Qiyas (Qudrat), and Tahsily inputs[span_2](start_span)[span_2](end_span).
* **University GPA Calculator:** Flexible term and cumulative GPA computation supporting both 4.0 and 5.0 scale systems[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span).
* **Saudi Universities & Majors Directory:** Comprehensive database enabling students to browse and search Saudi universities, colleges, and academic majors by degree level[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
* **Customizable Settings:** Personalization options including Light/Dark theme switching[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).

## Tech Stack & Architecture

* **Architecture Pattern:** Layered Architecture (3-Tiered Model)[span_9](start_span)[span_9](end_span).

* **Database & Tools:** MySQL Workbench, Postman[span_11](start_span)[span_11](end_span).
